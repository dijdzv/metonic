## P0-D contract evidence

The initial contract experiment used MoonBit 0.10.11+6ff76a5f9 on 2026-09-06.
See [environment.md](environment.md) and `toolchain.json` for toolchain inputs.

- `rpc/core` defines contract metadata and typed in-process bindings; it has no transport.
- `examples/p0/backend/api` defines GetUser input, output, domain error and procedure.
- `examples/p0/backend/handlers` supplies success and NotFound cases.
- `examples/p0/frontend/app` imports only the API package.
- `scripts/verify-types.ps1` checks isolated modules without backend handlers.

Procedure type parameters use `None` witnesses. Handlers are not part of the
contract. This binding experiment does not finalize a network client/server API.

The initial JS, WasmGC and native/MSVC runs each passed the handler test, frontend
execution, and the valid isolated check/build. All three targets rejected wrong
input, handler output, handler domain error, and client expected output types.
Compile-fail checks require a type-mismatch diagnostic, not just a nonzero exit.
These checks remain accessible through `mise run verify` and `mise run verify-native`.

## Initial clean-install evidence

[Windows CI run 34023759704](https://github.com/dijdzv/metonic/actions/runs/34023759704)
validated commit `59b4d221a89e818e4de4dea88a65912566625eb4` on windows-2022:
pinned-asset bootstrap, JS/WasmGC checks, and native contract checks.
That run did not include GPU, IME or OS accessibility tests. An initial
PowerShell module-resolution failure was resolved by using PowerShell 7 consistently.

CI is now manual. Formatting, static checks and tests run locally before commit;
main requires a PR but has no required status check. See

## Remaining P0 acceptance criteria

| Item | Current evidence and remaining work |
| --- | --- |
| P0-A Windows GPU | Offscreen rendering and hidden HWND lifecycle/input/resize checks pass. Visible presentation, real input and final bridge selection remain. |
| P0-B Browser GPU | JS/WasmGC real WebGPU, input, resize and stop checks pass on physical GPU and SwiftShader. Final target selection remains. |
| P0-C Async | Browser and native completion, cancellation, stale results and disposal are verified in bounded probes. General integration remains. |
| P0-D Contract | Minimal type boundary verified above. Wire codecs and transport remain separate work. |
| P0-E Protobuf/gRPC | Generator selection, cross-language encode/decode and native/browser protocol comparison remain. |
| P0-F Text | Font-backed Japanese/Latin layout, native GPU readback and JS/WasmGC input-to-GPU images pass. Native interactive integration and canvas editing remain. |
| P0-G IME | Real composition, selection and candidate placement need EditContext/textarea and Windows integration comparisons. |
| P0-H Semantics/devtools | Semantic state and launch-scoped CLI/MCP probes pass. OS accessibility and production exclusion remain unverified. |

P0 as a whole, R1/G1/N1 and an integrated UI are not complete.
