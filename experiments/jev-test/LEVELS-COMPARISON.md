# 5・6段階の分類比較

## 送信前に固定した条件

全1,880項目とcompact-symbolsの根拠情報を維持し、criteriaのみを変更する。
分類と選別条件は分離し、score < 2、confidence >= 0.6、P0+P1 >= 0.6を省略条件とする。
欠落、不正な確率、古い回答、変更された検証自身は実行側へ残す。

| 段階 | 5段階 | 6段階 |
|---|---|---|
| 0 | 関係なし | 同左 |
| 1 | 関係するが結果不変 | 同左 |
| 2 | 影響があり得るが経路は未特定 | 同左 |
| 3 | 具体的な影響経路があるが失敗は未確定 | 同左 |
| 4 | テストの期待に反し、失敗が見込まれる | 同左 |
| 5 | — | 提供された情報だけで期待違反を示せる |

5段階は4段階の「失敗し得る」を分割し、6段階は失敗の根拠が推測か明示されているかを分ける。
情報不足は最上位の段階へ追加しない。モデルに渡す情報で区別できるか自体を検討する。
高い段階に分類された件数だけで分類の正しさを証明しない。
危険側の段階が増えると期待スコアも変わるので、異なる尺度のscoreを直接比較しない。

試験はラベル変更と子Scope破棄を5・6段階で各1回（4回）。
事前指定対象を見逃した候補は採用せず、除外候補数と入力費用を比較する。
同程度なら安い方式を優先。有望な案のみClock取消・保存置換で確認し、ラベルを1回再評価。
追加の有料評価は最大7回。いずれも過去の3段階実験のDiffで、5・6段階では未評価。
意味的分類の完全な正解ラベルはないため、分類精度の測定とは区別する。
テスト本体は実行しない。

データ: .work/jev-metonic/levels-protocol.json。

## 結果と最終判断

**試作の最終推奨は追加条件付き4段階（compact-four + plan-four-guarded）。**
省略条件はscore < 2、confidence >= 0.6、P0+P1 >= 0.6。
5・6段階は比較用に残す。段階数を増やすこと自体を目的にせず、今回の調査はここで完了する。

| Diff | 条件付き4段階 | 5段階 | 6段階 |
|---|---:|---:|---:|
| ラベル名変更 | 700 | 511 | 705、反復685 |
| 子Scope破棄 | 496 | 477 | 588 |
| Clock取消 | 1,013 | 未実施 | 1,067 |
| 保存置換 | 1,433 | 未実施 | 1,380 |

数値は1,880項目中の除外候補。親子検証を含むため独立テストの削減数ではない。
各方式で事前指定した影響対象の見逃しは0。5段階は2 Diffで7組、6段階は4 Diffで10組、
ラベル反復で3組を再確認した。各方式に対応する安全策適用前の判断も確認した。
選別条件を結果に合わせて再調整していない。5・6段階以外の過去評価では使ったDiffなので、
完全に新規な変更集合への一般化は未確認。テスト本体は実行していない。

5段階は4段階より入力が約6%増え、今回の2例では除外も増えなかったため追加評価しなかった。
6段階は4段階より入力が約14%増。改善する例と減る例があり、ラベルの差は反復で逆転した。
余分な費用を常に払うだけの一貫した利点は今回の範囲では確認できなかった。
既存4段階の試験は各1回なので、方式間の精度・安定性の統計的な差を示す比較ではない。

6段階の追加した段階5が最大確率となったのは5回・9,400回答中1件のみ。
それは子Scope変更でのgit diff --quiet確認で、P5=0.41、confidence=0だった。
Diffだけではstaged/unstaged状態を確定できず、この1例を正しい「失敗の証明」とは数えない。
入力から確認できる情報を増やさずに「失敗を証明できる」を分けても、有用性を確立できなかった。
P5が0だったという意味ではなく、他の段階より高い確率になった回数を数えている。

有料評価は予定どおり7回、全13,160件の回答を受領し、IDと分割後の質問数を照合した。
モデルは全回jev-1.13.0。入力4,335,028 tokens、出力390,565 tokens。
今回の5・6段階調査分だけの合計で、過去の試作費用は含めない。
実行時間は今回14.3–18.1秒と過去より短かったが、時点・負荷が違うので段階数の効果としない。

分類を増やす場合は、今回の「ほぼ使われない分類」の増設ではなく、現行分類に収まらない
具体的な誤判定を根拠にする。入力不足、分類定義の不足、低confidenceの扱いを分けて検討する。
