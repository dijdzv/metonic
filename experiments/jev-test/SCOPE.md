# 現在の作業方針

ユーザー指定: 単体・統合・E2Eを含むすべてのテストの選択に集中する。
工程別の時間測定・準備集約・高コスト対象だけへの限定は今回の優先事項にしない。
不要なテストの除外数を増やしつつ、実際に失敗する必要なテストの見逃しを別軸で確認する。
削減率の目標値は置かない。安価なテストも選択対象から外さない。
