# Changelog

Notable changes to metonic are recorded here. No release has been published.

## Unreleased

### Added

- Typed procedure contracts with an isolated frontend API package.
- In-process handler binding and compile-failure tests for input, output, and domain errors.
- Windows x64 bootstrap with pinned MoonBit archives and SHA256 verification.
- mise tasks for formatting and native, JavaScript, and WasmGC verification.
- Windows CI using the same pinned bootstrap and verification tasks.
- Architecture proposals for development CLI/MCP integration and production exclusion.
- Contribution guidelines, issue templates, and a squash-merge workflow.

### Changed

- Updated the MoonBit baseline to 0.10.11 and migrated to `moon.mod`, `moon.pkg`, and `Debug`.
- Organized public documentation around architecture, development, decisions, and verification.

### Not yet available

- GPU rendering, asynchronous UI tasks, text/IME integration, network RPC, or a running CLI/MCP adapter.
